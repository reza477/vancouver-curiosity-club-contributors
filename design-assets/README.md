# Brand artwork source

`brand-icon-master.png` is the canonical raster source for the Vancouver
Curiosity Club mark. Do not edit generated public icons independently.

The open circle represents an available place in the community; the amber
spark crossing its opening represents curiosity entering the conversation.

After an approved replacement, run:

```powershell
npm run brand:generate
```

The generator writes the favicon sizes, application icons, maskable icon, and
Open Graph image under `public/`. Review every generated output for crop,
contrast, legibility, and unintended visual artifacts, then run the brand asset
tests before committing the source and outputs together.

The artwork is proprietary project material. Repository access does not grant
permission to reuse it outside this website.
