# Phase 6 organizer guide

This guide applies only after a Phase 6-or-later version is explicitly
deployed and your matching ChatGPT identity has an active assigned-club
membership.

## What an Organizer can do

General page, club, Community, navigation, brand, legal, and media management
remains Owner/Administrator-only.

Public Program profiles are also Owner/Administrator-managed and are nested
under an active parent club in the same organization. An unassigned core
Program remains private until an Owner or Administrator assigns that parent;
Organizer access to an event does not grant general Program-CMS authority.

For an event in an assigned club that you own or co-organize, you may select
an artwork asset that an Owner or Administrator has already made public-ready.
The existing event and website-publication authorization rules still apply.
Choosing artwork is a content-only edit: it increments the event content
version, creates revision and audit history, and never changes its schedule
version or bypasses conflict checks. The same Website publication section
provides bounded public SEO title and meta-description fields; those values
remain private until the event is genuinely published.

You may also prepare and explicitly publish your own public-attribution
profile. Saving the display name, optional biography, approved profile photo,
and consent creates a private draft only. **Publish public attribution** is a
separate confirmation; **Revoke public attribution** removes that public name,
biography, and photo immediately. This does not authorize general CMS or media
management.

Public attribution still requires an event-level gate. The event must enable
public host display and select you as an eligible host. Public output may then
contain only the confirmed display name, bounded biography, and approved photo
alt, credit, and responsive dimensions. It never exposes your email, role,
assignments, auth identifiers, private profile fields, newer private draft, or
R2 object key.

## Selecting event artwork

The selector includes only ready same-organization assets with:

- approved rights;
- confirmed or not-applicable participant consent;
- required credit;
- useful alt text when the image is informative.

You cannot upload, replace, approve, edit, publish, or delete media. You also
cannot fetch the original upload; private event-scoped access is limited to
the generated WebP variants.

If artwork becomes ineligible before the save commits, the complete edit rolls
back and your submitted event values remain available for correction. If it
becomes ineligible before a due scheduled website publication, the job fails
closed, remains nonpublic, and creates a private actionable notification.

Do not put legal-status, nonprofit, society-registration, charity,
tax-deductibility, or tax-receipt claims in event title, summary, description,
location/access notes, cost, preparation, accessibility, or SEO fields.
Those claims require the separate exact Owner-confirmed legal workflow.
Neutral factual event copy remains available.

## Public behavior

Published event cards and details use responsive WebP variants, the canonical
asset alt text, credit, focal point, and each variant's real stored dimensions.
Public routes never expose R2 object keys, original filenames, source notes,
rights notes, consent notes, actor IDs, or original image bytes. Event
metadata prefers the event's approved artwork and falls back to the current
published site Open Graph setting without inventing an image size or alt text.

Unpublishing, archiving, deleting, restoring, or cancelling a not-yet-
published scheduled event retires the public artwork usage. A public
cancellation or eligible completed public event may retain truthful artwork
with its existing public page.

Website publication still does not publish or edit Meetup. Phase 6 adds no
public form, import/export, email, internal RSVP, attendee account, comment,
message, forum, or chat workflow.

Editor role — **Not implemented — authorized cut**. Viewer role — **Not
implemented — authorized cut**. Realtime subscriptions — **Not implemented —
authorized cut**.

The Phase 6 candidate is not deployed. These controls are available only after
a later explicitly authorized Phase 6-or-newer owner-only deployment.
