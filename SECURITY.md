# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or community channel.

Send a minimal private callback request through the website's
[Contact form](https://vancouvercuriosityclub.com/contact). State that it is a
security report and provide a safe way for the owner to reply. Do not include
exploit details, credentials, personal information, or private records in the
form. Share technical details only after the owner establishes a suitable
private channel.

When the private channel is established, include:

- the affected route or component;
- clear reproduction steps;
- the potential impact;
- whether personal, organizer-only, or authentication data may be involved;
- any suggested mitigation.

Do not access data that is not yours, test against real submissions, disrupt the live service, or retain sensitive information while investigating.

## Supported version

Security fixes are applied to the current production branch. Historical commits and undeployed candidates are not supported releases.

## Disclosure

Please allow maintainers time to investigate and deploy a correction before public disclosure. The project does not offer a bug bounty unless a separate written agreement says otherwise.
