# Changelog

This file records supported source releases of the Vancouver Curiosity Club
website. Development history before Version 1 remains available in Git.

## [1.0.0] - 2026-08-25

### Added

- Institutional pages for the Society's mission, governance, public programs,
  partnerships, and community contact paths.
- Responsive event discovery, club pages, event details, calendar feeds, and
  source-faithful Meetup synchronization.
- Owner-controlled content, forms, email delivery, media, D1/R2 persistence,
  and scheduled maintenance boundaries.
- Contributor, architecture, security, release, recovery, and UI/UX handoff
  documentation.

### Changed

- Established `main` as the supported Version 1 collaboration baseline.
- Standardized owner-reviewed branches, pull requests, CI checks, and
  owner-controlled Sites releases.
- Refined public layouts, mobile navigation, typography, artwork, and bounded
  hot-path data delivery.

### Security

- Production credentials, hosted data, publishing access, and maintenance
  signing remain outside contributor branches and source control.
